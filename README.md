# Story Zoo

## Tentang Project

Story Zoo adalah website sederhana yang dibuat menggunakan HTML dan CSS. Website ini memiliki beberapa halaman utama, yaitu Home, About, dan Koleksi.

Halaman About digunakan untuk memberikan informasi mengenai website Story Zoo dan cerita singkat tentang project.

## Tujuan Project

Project ini dibuat untuk mempraktikkan pembuatan halaman website menggunakan HTML dan CSS.

Beberapa materi yang digunakan dalam project ini:

- Struktur dasar HTML
- Navigasi antar halaman
- Heading
- Paragraph
- Table
- Button
- Link
- Class dan ID
- External CSS

## Struktur Halaman About

Halaman About terdiri dari beberapa bagian:

- Head
- Header
- Navigation
- Main
- About
- Footer

## Navigasi Website

Website memiliki beberapa menu navigasi:

| Menu | Halaman |
|---|---|
| Home | beranda.html |
| About | about.html |
| Koleksi | koleksi.html |

Navigasi digunakan untuk berpindah dari satu halaman ke halaman lainnya.
